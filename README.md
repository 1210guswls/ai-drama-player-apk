0.1.4는 GitHub 승인 후 연결 화면이 반복되는 문제를 수정합니다. 브라우저 이동·앱 프로세스 종료 후에도 만료 전 승인 대기를 암호화된 상태에서 복구합니다. 0.1.3에서 연결이 끊겼다면 업데이트 후 새 코드로 한 번 다시 승인해 주세요.

처음에는 로그인 없이 내장 오리지널 체험본을 열 수 있습니다. 비공개 라이브러리는 앱의 **내 라이브러리 연결 → GitHub로 연결 → 코드 복사하고 GitHub 열기**에서 8자리 코드를 승인하면 됩니다. 토큰을 직접 만들 필요가 없고 이후에는 자동 연결됩니다. 인증 정보는 휴대폰의 Android Keystore로 암호화합니다.

전용 GitHub App은 ai-story-library 하나의 Contents/Metadata 읽기 전용입니다. GitHub 설정에서 접근을 해제할 수 있습니다. ChatGPT의 GitHub 연결은 휴대폰 앱 인증과 별개입니다.

0.1.2부터 홈 위젯의 업데이트를 누르면 새 버전 확인·다운로드·파일 검증·설치 세션 전달·임시 APK 정리까지 이어집니다. 처음 한 번 설치 허용과 Android가 요구하는 승인만 필요할 수 있습니다.

이 저장소는 독립 앱의 APK·update.json·파일 해시만 배포합니다. 소스코드, 비공개 스토리, TTS 모델, 토큰과 서명키를 게시하지 않습니다. 기존 게임의 APK·배포 경로를 변경하지 않습니다.
